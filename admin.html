BCA HUB Admin

Admin access

Enter your temporary access code to open the upload panel.

Temporary mode: this code check is visible in the public website files. It is only a basic screen lock, not secure authentication. Do not upload private or sensitive files.

Learning materials

Choose where your material belongs, then use + Add to upload it to the matching GitHub folder.

Select a semester to view its subjects.

After you press Add, GitHub opens the selected folder. You can choose multiple PDFs or images in one upload, then commit them to GitHub.

Choose a semester, subject and material type to load files.

Exam timetable

Add exam names and dates, then publish the generated timetable to GitHub.

Paste the copied data into exam-timetable.json on GitHub and commit it to update the public countdown.

Remove opens GitHub's delete confirmation page for the selected file. Sign in and confirm the commit there.
