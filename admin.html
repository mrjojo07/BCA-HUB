How to add a PDF

  1. Choose Upload PDFs and files above and sign in to GitHub.
  2. Open or create a folder such as resources/semester-1/.
  3. Select your PDF, then commit the upload to the main branch.
  4. Copy the file link and add it to the matching semester section on the homepage.

Only upload materials you have permission to share. Check the correct University of Calicut syllabus and admission batch before assigning subjects to semesters.
