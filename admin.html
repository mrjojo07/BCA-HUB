Learning materials

Choose where your material belongs, then use + Add to upload it to the matching GitHub folder.

After you press Add, GitHub opens the selected folder. Sign in to your own GitHub account, choose your PDF or image, and commit the upload.

Note: this temporary workflow uploads the file to the repository. It does not automatically publish a clickable item on the homepage yet.
